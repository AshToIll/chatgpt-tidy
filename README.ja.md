# ChatGPT Tidy

[简体中文](README.md) | [English](README.en.md) | 日本語

**通常ユーザー：[インストール用 ZIP](https://github.com/AshToIll/chatgpt-tidy/releases/download/v0.5.2/chatgpt-tidy-0.5.2.zip) · [インストール手順](#インストール-052)**（Node.js などの開発ツールは不要です）

ブラウザー版 ChatGPT の会話をすっきり整理する小さな拡張機能です。自分用に作ったものを、必要な方にも公開しています。

もともとはタイトル整理のために作りましたが、今では次の機能も備えています。

- **時間表示**：会話やメッセージの日時、メッセージ番号を表示します。
- **タイトル整理**：現在の会話や複数の会話のタイトルをプレビューし、日付ルールに沿って名前を揃えます。
- **お気に入り**：会話をお気に入りに登録し、グループで整理できます。元の会話にも移動できます。
- **ブックマーク**：重要なメッセージを登録し、グループで管理できます。該当メッセージにも移動できます。
- **検索**：キーワードや会話の日付で会話を検索します。
- **エクスポート**：会話やブックマークしたメッセージを Markdown、TXT、JSON、PDF で保存します。
- **設定**：表示言語（簡体字中国語、繁体字中国語、英語、日本語）、タイムゾーン、テーマカラーの変更や、データのバックアップができます。

OpenAI とは関係のない個人プロジェクトです。ChatGPT のページの変更により、機能に影響が出る場合があります。

## インストール 0.5.2

パソコン版 Chrome / Edge 116 以降を使用します。以下は 0.5.2 の例です。

**インストール動画**（約 1 分 24 秒、中国語テキスト・BGM 付き）：[MP4 をダウンロード](https://github.com/AshToIll/chatgpt-tidy/releases/download/v0.5.2/ChatGPT-Tidy-install-guide-zh.mp4)

### 通常ユーザーのインストール

1. **ダウンロード：** このページの **[インストール用 ZIP](https://github.com/AshToIll/chatgpt-tidy/releases/download/v0.5.2/chatgpt-tidy-0.5.2.zip)** をクリックし、**`chatgpt-tidy-0.5.2.zip`** を保存します。Releases では **Assets** からこの名前のファイルをクリックします。**「Source code (zip)」は押さないでください**。同じファイル名でダウンロードされますが、中身はソースコードで、そのままではインストールできません。
2. **展開：** Windows は ZIP を右クリック →「すべて展開」→「展開」。Mac は Finder で ZIP をダブルクリックします。展開すると **`chatgpt-tidy-0.5.2` フォルダー**ができます。整理で消えない場所に置きます（例：自分で作った「ブラウザー拡張」フォルダー）。「ダウンロード」に置いたままにせず、その後は削除・移動・名前の変更をしないでください。ブラウザーは起動のたびにこのフォルダーから拡張機能を読み込みます。
3. **拡張機能管理：** Chrome のアドレスバーに `chrome://extensions`、Edge には `edge://extensions` と入力し、Enter キーを押します。
4. **デベロッパー モードをオン：** Chrome は右上の「デベロッパー モード」、Edge は左側の一番下の「開発者モード」をオンにします（ウィンドウが狭いときは、先に左上の ☰ を押します）。英語表示では Developer mode です。その後もオンのままにしてください。
5. **フォルダーを読み込む：** Chrome は「パッケージ化されていない拡張機能を読み込む」、Edge は「展開して読み込み」（英語表示では Load unpacked）→ **`chatgpt-tidy-0.5.2` フォルダー全体**を選択（下の図を参照）→ Windows は右下の「フォルダーの選択」を押します。Mac は表示に合わせて「選択 / Select」または「開く / Open」を押します。
6. **Tidy を開く：** 同じブラウザーで [chatgpt.com](https://chatgpt.com) を開いてログイン → アドレスバー右側の **ChatGPT Tidy のアイコン**（黒い花の形に時計の針）を押します。サイドパネルが表示されたらインストール完了です。ページを再読み込みすると使い始められます。ツールバーにアイコンがない場合は、アドレスバー右側のパズルの形をした「拡張機能」ボタン 🧩 を押し、一覧の **ChatGPT Tidy** を押します。ツールバーへの固定がおすすめです。

**手順 5 で選ぶ階層：** 中のファイルではなく、フォルダー全体を選ぶのがポイントです。開いたときに `manifest.json` が直接見えれば正解です。選択画面でファイルが灰色になったり表示されなかったりしても問題ありません。

```text
chatgpt-tidy-0.5.2/       ← このフォルダー全体を選び、確定
├── manifest.json
├── app/
├── assets/
└── …
```

**うまくいかないとき：**

- **「マニフェスト ファイルが見つからない」などのエラー**（Manifest file is missing or unreadable）：選んだ階層が違うか、Source code をダウンロードしています。`manifest.json` が直接見えるフォルダーを選び直してください。
- **ChatGPT Tidy を押しても何も起きない：** サイドパネルは ChatGPT のページでのみ開きます。ChatGPT のタブに切り替え、再読み込みしてからもう一度押してください。
- **拡張機能が急に使えなくなった：** デベロッパー モード（Edge は開発者モード）がオフになると、このような拡張機能も無効になります。拡張機能管理でオンに戻してください。

Mac の手順はブラウザーの標準的な画面に基づいています。macOS 実機での検証はまだ完了していません。ボタン名は実際の画面に合わせてください。

### 開発者向けソースコードのインストール

通常ユーザーはこの節を読む必要はありません。ソースコードを展開し、中の **`src` フォルダー**を読み込みます。他の手順は上と同じです。

| ダウンロード元 | ファイル | 展開後に読み込むフォルダー（例） |
| --- | --- | --- |
| Releases → Assets | `chatgpt-tidy-0.5.2-source.zip` | **`chatgpt-tidy-0.5.2-source/src`** |
| Code → Download ZIP | `chatgpt-tidy-main.zip` | **`chatgpt-tidy-main/src`** |
| Releases → Source code (zip) | `chatgpt-tidy-0.5.2.zip`（GitHub 自動生成のソース） | **`chatgpt-tidy-0.5.2/src`** |

```text
chatgpt-tidy-0.5.2-source/
└── src/                  ← このフォルダーを選び、確定
    ├── manifest.json
    ├── app/
    └── …
```

## 更新とバックアップ

ChatGPT Tidy のサイドパネルにある **設定 → ライブラリのバックアップ** から、お気に入りとブックマークのデータを JSON ファイルにバックアップできます。

更新の手順：

1. **設定 → ライブラリのバックアップ** から、先にバックアップを保存します。
2. 新しいインストール用 ZIP をダウンロードして展開します。
3. 新しいフォルダーを開き、中身をすべて選択してコピーし、元のインストール先フォルダーに貼り付けます。同じ名前のファイルについて聞かれたら「置き換える」を選びます。
4. 拡張機能管理で ChatGPT Tidy のカードにある再読み込みアイコン ↻ を押し、ChatGPT のページも再読み込みします。

先に拡張機能を削除したり、拡張機能のデータを消去したりしないでください。また、新しいバージョンを別のフォルダーから読み込まないでください。ブラウザーが別の拡張機能として扱うため、これまでのお気に入りとブックマークが表示されません。

ブラウザーやパソコンを変更した場合は、上の手順で ChatGPT Tidy をインストールし、元の ChatGPT アカウントにログインすれば、同じ場所からバックアップを読み込めます。

同じアカウントに個人用・チーム用のワークスペースが複数ある場合は、バックアップ時に使用していたワークスペースに切り替えてから読み込んでください。

## 開発

開発やソースコードの変更を行う場合は、ブラウザーに `src` フォルダーを読み込んでください。

**Node >=24** を使用し、リポジトリのルートで次を実行します。

```sh
npm ci
npm run verify
```

実行に必要なライブラリとフォントはソースコードに含まれています。構成、ストレージ、ビルド、リリースの手順は[開発ドキュメント](docs/README.md)をご覧ください。
