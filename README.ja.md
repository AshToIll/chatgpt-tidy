# ChatGPT Tidy

[简体中文](README.md) | [English](README.en.md) | 日本語

ブラウザー版 ChatGPT の会話をすっきり整理する小さな拡張機能です。自分用に作ったものを、必要な方にも公開しています。

もともとはタイトル整理のために作りましたが、今では次の機能も備えています。

- **時間表示**：会話やメッセージの日時、メッセージ番号を表示します。
- **タイトル整理**：現在の会話や複数の会話のタイトルをプレビューし、日付ルールに沿って名前を揃えます。
- **お気に入り**：会話をお気に入りに登録し、グループで整理できます。元の会話にも移動できます。
- **ブックマーク**：重要なメッセージを登録し、グループで管理できます。該当メッセージにも移動できます。
- **検索**：キーワードや会話の日付で会話を検索します。
- **エクスポート**：会話やブックマークしたメッセージを Markdown、TXT、JSON、PDF で保存します。
- **設定**：表示言語（簡体字中国語、繁体字中国語、英語、日本語）、タイムゾーン、テーマカラーの変更や、データのバックアップができます。

OpenAI とは関係のない個人プロジェクトです。ChatGPT のページの変更により、機能に影響が出る場合があります。

## インストール 0.5.0

Chrome / Edge 116 以降を使用してください。通常はインストール用の [`chatgpt-tidy-0.5.0.zip`](https://github.com/AshToIll/chatgpt-tidy/releases/download/v0.5.0/chatgpt-tidy-0.5.0.zip) をダウンロードし、そのまま使い続けるフォルダーに展開してください。

1. Chrome では `chrome://extensions`、Edge では `edge://extensions` を開きます。
2. 「デベロッパー モード」を有効にし、展開済みの拡張機能を読み込むボタンから、`manifest.json` のあるフォルダーを選びます。
3. ChatGPT のページを再読み込みし、ブラウザーの拡張機能メニューから **ChatGPT Tidy** をクリックすると、サイドパネルが開きます。

GitHub の「Code → Download ZIP」でソースコードをダウンロードした場合は、展開後にリポジトリのルートではなく、その中の `src` フォルダーを選んでください。

## 更新とバックアップ

**設定 → ライブラリのバックアップ** から、お気に入りとブックマークのデータを JSON ファイルにバックアップできます。

更新前にバックアップを保存し、新しいバージョンのファイルで元のインストール先を上書きしてから、拡張機能と ChatGPT のページを再読み込みしてください。先に拡張機能を削除したり、拡張機能のデータを消去したりしないでください。

ブラウザーやパソコンを変更した場合も、元の ChatGPT アカウントにログインすれば、バックアップを読み込めます。

同じアカウントに個人用・チーム用のワークスペースが複数ある場合は、バックアップ時に使用していたワークスペースに切り替えてから読み込んでください。

## 開発

開発やソースコードの変更を行う場合は、ブラウザーに `src` フォルダーを読み込んでください。

**Node >=24** を使用し、リポジトリのルートで次を実行します。

```sh
npm ci
npm run verify
```

実行に必要なライブラリとフォントはソースコードに含まれています。構成、ストレージ、ビルド、リリースの手順は[開発ドキュメント](docs/README.md)をご覧ください。
