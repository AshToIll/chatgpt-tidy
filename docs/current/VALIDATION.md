## 已证实并修复的关键问题

| 问题 | 当前规则及回归 |
| --- | --- |
| 错误目标的导航回执先占用完成标识 | 校验标签、意图和精确目标后才消费；连接期间暂存也先核验，后续正确回执可正常完成 |
| 成功导航后迟到 OPEN 失败复活旧提示 | 操作所有权和终态分离；书签失败先撤销旧意图再发布本次反馈，不立即吞掉错误 |
| 连接重试已耗尽却一直“正在连接” | 明确进入 stalled，提供重新连接；只有确知旧页面失效才要求刷新，不自动重放业务 |
| 备份或标题未知写入切栏后丢失 | 显示实例与操作账本分离，保留待核对状态和下一步，不用 TTL 当作已解决 |
| 标题批次旧账号空回执、旧返回会话异常覆盖新状态 | 账号/操作代际核验；写入前计划过期与已派发后未知结果分别处理 |
| 偏好权威恢复仍显示旧读取错误、规则乱序核对失败 | 读取错误和写入未知分开；成功旧回执不制造新的错误代际，新失败仍不能被旧读取清掉 |
| 导出取消 A 的迟到回执覆盖 B | 按任务/操作代际归属；未知提交仍锁定，不因同账号重新验证提前允许重复任务 |
| 导出失败因 hide/show 自动重读 | 失败恢复只由明确重试或真实输入变化触发，不让 render 或栏目重现偷偷重试 |
| 未知身份被当作新账号导致导出篮丢失 | 未验证期锁定并保留；确认同账号恢复原篮，确认不同账号才清除 |
| 批量单文件刷新时丢失自定义文件名 | 临时未就绪不当作有效输出集合改变；同集合保留文件名，真正换集合才重置 |
| 无关快照/导出轮询替换搜索输入 DOM | 收窄到对应栏目重绘；实际搜索输入与中文组合输入节点不被无关事件替换 |
| 网页书签旧操作失败覆盖后来的成功 | 每个按钮的操作代际校验，旧回调无权重新出现提示 |
| 诊断清空后的旧包/旧 ACK 回填、回放乱序 | generation、精确注册、串行存储与有界游标；保留记录始终有对应高水位，旧回执不能复活历史 |

上述竞态包含独立审查中发现并补充的失败→通过回归；不能用“目录移动没有改变功能”代替这些验证。

## 文案与交互现在怎么管理

- **594 个在用文案键**（收藏/书签共用名称校验及移组标签，新增收藏操作按钮标签；原阶段统计见下方历史记录）：公共及七栏 catalog 是唯一手写文案源。原 603 键经逐条追链后退役 7 个历史未用键，详见 `src/messages/retired-keys.json`；603 包括按钮、标签、帮助、导出内容及提示，不是 603 个错误。新增 17 个四语言键通过逐键 allowlist 审核，未整体重录或放宽原翻译基线。
- **23 个提示表面**（显示位置/控制器，不是句数）：登记所属功能、显示条件、下一步、清除条件和调用位置，见 [MESSAGE_INDEX](MESSAGE_INDEX.md)。
- 短反馈、持续条件、操作状态有共同生命周期规范；正常取消不冒充错误，旧定时器不能清掉新提示。
- 导航读取失败是短反馈；鼠标悬停或键盘聚焦时暂停计时。写入未确认、任务和恢复锁不会因为过几秒、换语言或换栏目被当成成功。
- 修改文案改 catalog 后运行构建；不手改生成的 i18n、页面运行时、模板文字、索引或 MAIN bundle。
- 架构门禁拒绝旧运行路径、feature/platform 反向依赖 app、跨 feature UI 依赖及静态 ESM 循环。动态表达式和 classic global 装配的静态分析限制明确列出，仍需运行验证。

## 追溯边界

“这句话可能由哪些源码条件触发”由索引、登记和控制器分支回答；“上一次实际触发的是哪一条分支”由当时观测回答，两者不混淆。

当前入口固定在设置底部的“排查日志”，不在其他栏目或公共连接区展示。断连时仍能在设置复制/确认后清空日志，其他六栏及设置业务表单保持原准入限制。没有新增自动上传、自动重试或修改业务的诊断能力。

- 当前文档观测器最多 256 条；Worker 汇集到 `chrome.storage.session`，最多 512 条、256 KiB、128 个上下文。
- 已接收的记录可跨侧栏关闭保留；浏览器会话结束或构建改变后不承诺保留。页面关闭前尚未送达的记录不保证送达。
- 只保存白名单代码、构建、关联号、阶段、断连类型和类型化状态；不保存聊天正文、标题、搜索词、账号、URL、凭据或任意异常原文。
- 容量淘汰、待发送、存储或运输失败明确暴露；复制时存在已知缺失会提示诊断可能不完整，不把“没记录”说成“没发生”。
- 未保留类型化原因的路径明确标记观察级原因，不根据文案猜根因。
- 备份待核对账本保留于当前侧栏文档；跨关闭的业务恢复未扩展为持久化协议。标题/导出原有持久操作与下载回执规则保持。
- 清空诊断只清记录，不隐藏提示、不解除写入锁、不重发操作。

## 实验范围与未执行项

浏览器检查运行真实生产模块/DOM/布局与导航控制，使用临时浏览器配置和合成数据；不读写用户浏览器配置或实际账号。补充诊断检查运行真实 worker service/session store，但 Chrome storage 和剪贴板边界使用隔离内存适配器，验证实际复制文本与存储回执，不声称验证了系统剪贴板或真实扩展 worker 进程。

尚未执行真实账号操作、用户已安装扩展升级和候选包人工验收。目录变更不会自动让浏览器切换到新目录；旧安装仍需明确更新，不能把源码版本号修改当作已安装交付。独立安装的资料边界仍按 [STORAGE](STORAGE.md)，不要把不同扩展安装的数据隔离误认为清理了旧资料。

## 真实安装实例验收：生成图与重复会话日期（2026-09-29）
