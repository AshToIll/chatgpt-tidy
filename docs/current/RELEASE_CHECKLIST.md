# 发布清单

每次发布检查实际源码和产物；没有执行的项目标明未测，不复制旧结果。

- [ ] 名称为 ChatGPT Tidy，`package.json` 与 `src/manifest.json` 版本一致。
- [ ] 使用 Node >=24 和 `npm ci`；对应 bundle、图标已重新生成。
- [ ] `npm run verify` 通过，代码差异中没有意外文件或调试内容。
- [ ] `npm run verify:release` 已运行，实际浏览器及失败/未测项有说明。
- [ ] 解压安装包加载后，刷新 ChatGPT、重开侧栏，各入口可用。
- [ ] 工具栏深浅图标、白色实心指针、侧栏白描边及完整名称清晰可见。
- [ ] 标题单条/批量预览和确认正常；中断只读核对，不自动重发；accepted 不冒充 verified。
- [ ] 收藏、书签、分组及刷新/重开后资料正常，切账号/工作区不会串资料。
- [ ] 旧版备份可在同归属新版恢复；已有条目保留，错误文件不写库。
- [ ] 真机对照同一官方关键词命中：点击 Tidy 结果卡片的标题、摘要与空白区域效果一致；有消息命中时由官方定位并显示黄色高亮，不把交接回执当作定位成功。
- [ ] 真机检查日期结果整卡跳转至最新消息，包括从关键词命中切到同一会话；普通会话与项目会话的官方左栏均呈现原生选中底色，关键词和日期跳转都不整页闪动，Tidy 右侧卡片样式保持不变。
- [ ] 书签精确定位和收藏最新消息正常；取消、晚到回包和新动作不会复活旧导航，也不会出现过期请求的错误提示。
- [ ] Markdown/TXT/JSON/PDF 实际打开检查，链接地址、批量 ZIP 内容、中文和其他使用到的字形正常。
- [ ] 媒体开关开启时，Markdown/TXT 只保留说明与可用链接，PDF 嵌入可读取的图片，JSON 保留媒体信息；各格式均不备份附件文件本体。
- [ ] 后台导出、取消、另存为及下载结果提示正常；关闭侧栏不截断已开始任务。
- [ ] 项目 LICENSE、第三方库/字体的许可原文与来源索引随包保留；已知来源说明不丢失。
- [ ] 包的文件清单/哈希与源码一致，不含凭据、个人会话、Git 历史、缓存或草稿；独立解压源码可完成 `npm ci` 和 `npm run verify`。
- [ ] README 与实际安装方式一致；上传或公开前确认目标，打包完成不等于发布完成。

操作命令见 [DEVELOPMENT](DEVELOPMENT.md)，数据边界见 [STORAGE](STORAGE.md)。
