# 七栏功能职责与协作契约

本文说明 **0.5.0 架构候选**的现行源码。它是功能/状态合同，不是发布声明或“全部无 bug”的保证；验证范围见 [VALIDATION](VALIDATION.md)。

## 七栏入口

| 栏目 | 界面入口（相对 `src/features/`） | 固定文案源（相对 `src/messages/catalogs/`） | 主要共享底座 |
| --- | --- | --- | --- |
| 时间显示 | `time/ui/time-view.js`、`time-template.js` | `time.json` | 偏好、时间格式、快照、页面连接 |
| 标题整理 | `titles/ui/title-organization-view.js` | `titles.json` | 目录、身份、页面通信、日期格式 |
| 收藏 | `favorites/ui/favorites-view.js` | `favorites.json` | 账号资料、当前会话卡片、导航、导出选择 |
| 书签 | `bookmarks/ui/bookmarks-view.js` | `bookmarks.json` | 账号资料、当前会话卡片、精确导航、导出选择 |
| 搜索 | `search/ui/search-view.js` | `search.json` | 目录、页面通信、导航、导出选择 |
| 导出 | `export/ui/export-view.js` | `export.json` | 身份、页面通信、资料来源、浏览器下载 |
| 设置 | `settings/ui/settings-view.js`、`settings-template.js` | `settings.json` | 偏好、主题、账号资料、页面连接 |

这是七栏，不是七套系统。每栏按需设 `ui/background/chatgpt/storage/model`，导出另有 `engine`。公共按钮与连接状态在 `common.json`，以稳定键归属为准，不因显示在某栏就复制文案。

栏目样式在本栏 `ui/`，共享样式在 `platform/ui/`，`app/sidepanel/panel.css` 维持级联装配。逐文件位置见 [FILE_GUIDE](FILE_GUIDE.md)，消息运输与准入见 [ARCHITECTURE](ARCHITECTURE.md)。

## 1. 时间显示

- **负责/输入：** 时间开关、列表时间规则、消息时间位置/精度、编号、折叠与实时预览；输入偏好及当前快照。
- **输出：** 偏好字段补丁与预览；网页 `time-presentation.js` 使用同一偏好显示时间和编号。
- **状态 owner：** `time-view.js` 拥有控件、折叠和监听；`platform/preferences/preference-controller.js` 拥有读写状态。壳只注入保存与可用性。
- **退出/取消：** 销毁解除监听；页面不可操作时禁用业务，不自行重新连接。
- **消息布局：** 正文后模式按正文/气泡 → 时间、编号与书签 → 原生操作栏排列；用户靠右、助手靠左。两展示模块共用消息 DOM 定位规则，不搬动原生内容；只有书签时也跟随前/后设置。消息编号使用小号视觉开关，保留独立操作与较大的点击区。
- **提示：** 时间标签查 `time.json`；偏好和连接状态复用公共表面。关闭时间显示只禁用时间相关选项；消息编号保持独立可操作且不灰显，不清除全局设置错误。

## 2. 标题整理

- **负责/输入：** 当前会话与批量整理；输入账号/会话、规则、目录、选择和明确确认。
- **输出：** 预览、不可变计划、写入及回执；HTTP accepted 与读回 verified 分开，页面投影不算服务端核验。
- **状态 owner：** `title-organization-view.js` 管当前/批量入口；`title-view.js` 与 `title-batch-view.js` 管各自操作。后台 service 与持久化 operation 管执行/回执。规则和目录有各自控制器。
- **退出/取消：** 隐藏或离开停止后续批次步骤；返回只读核对，不自动续写。旧账号/会话的确认不能重新生效。
- **提示原因和下一步：** 预览过期需重新预览；批量写入前计划失效允许新预览，不假称未知写入。限流/连接失败按对应入口恢复；写入结果未知必须核对，不将“读取失败”当成“写入失败”。规则保存与标题写入分开呈现，同字段后续成功可收敛旧保存失败，不能顺带清除未知标题写入。
- **消失条件：** 普通操作提示随对应状态变化清除；未确认写入独立于栏目可见性保留，核对失败也不解除恢复锁。新操作必须满足既有确认规则，不能靠换栏或超时抹掉结果。
- **表面：** `titles.current.notice`、`titles.current.recovery`、`titles.batch.notice`、`titles.batch.receipt`、`titles.rules.status`；文案在 `titles.json`。

## 3. 收藏

- **负责/输入：** 会话收藏、分组、排序、分页、移动/删除及网页星标；输入当前账号资料、会话、选择投影和用户动作。
- **输出：** 资料变更、打开会话、导出选择意图；网页和侧栏共用同一账号库。
- **状态 owner：** `favorites-view.js` 管列表交互；`favorites-domain.js` 管领域变换，`favorites.js` 是存储入口；共享 library controller 管身份/加载/修订，壳的 library-panel controller 编排动作。
- **退出/取消：** 切账号撤销旧回包权；离开、新导航或用户接管按公共导航 owner 撤销，不影响其他栏的新意图。分组管理菜单、图标浮层及条目菜单遵循下方的收藏/书签共享交互契约；离栏不丢尚未提交的名称草稿，身份失效才清除草稿。
- **提示原因和下一步：** 读取失败按类型重试；变更回执未知先看资料，不假定保存失败。导航已打开而 latest 未定位单独说明。
- **消失条件：** 短反馈由 notice controller 管；收藏导航失败绑定本次 intent，5 秒到期、新动作或离栏清除，不让旧回执复活。网页错误由 `favorites-presentation.js` 管，点击提示、再次操作或节点移除清除，普通重绘/换语言不清除。
- **名称校验：** 新建/重命名共用去首尾空白规则；空名在原输入框旁提示“请输入分组名称”，不请求、不关闭编辑、不替用户填回默认名。后端其他确定性校验拒绝只作短失败反馈，真正写入未知仍保持原有待核对语义。
- **条目分组：** 普通列表的会话导航和 `···` 是相邻独立按钮；菜单调用既有 move/remove，不以取消再收藏实现移组，不重置收藏时间或元数据。导出选择模式不呈现管理菜单。
- **表面：** `favorites.library-status`、`favorites.group-name-validation`、`page.favorite.error` 和共享 toast；文案在 `favorites.json` / `common.json`。

## 4. 书签

- **负责/输入：** 消息书签、分组、筛选、排序、网页按钮/数量与精确消息跳转；输入账号资料、消息标识/摘要、当前会话及选择投影。
- **输出：** 资料变更、精确导航、定位回执、导出选择意图。
- **状态 owner：** `bookmarks-view.js` 管列表；`bookmark-navigation.js` 拥有本栏导航目标；资料身份与事务复用 library，业务规则和网页按钮归书签。
- **退出/取消：** 以精确导航 ID 管理；离开/隐藏/身份失效或新导航撤销旧意图。完成回执还须匹配书签目标，不能只凭相同 ID 消费。菜单、名称编辑和删除确认遵循下方的共享交互契约；局部关闭浮层不能重绘搜索框或打断中文输入。
- **提示原因和下一步：** 区分打开失败、精确定位未完成与资料变更未知；按提示查看书签或重新定位，不混成一种通用失败。
- **消失条件：** 侧栏短反馈归 notice controller；网页错误在点击、再次操作或节点移除时清除。书签数量打开动作的旧失败不能在新动作后复活，不为所有错误新增统一自动消失规则。
- **表面：** `bookmarks.library-status`、`bookmarks.group-name-validation`、`page.bookmark.error` 及共享 toast；文案在 `bookmarks.json` / `common.json`。

## 5. 搜索

- **负责/输入：** 关键词与日期、日历、分页、命中摘要及日期来源导出；输入固定绑定标签、账号、条件和用户交互。
- **输出：** 结果/部分失败、导航意图、日期导出候选。关键词读远端搜索；日期读共享目录，不读取聊天历史冒充目录。
- **状态 owner：** `search-query-controller.js` 唯一写条件、页码、读取代际和查询结果；`search-result-navigation.js` 管点击目标/回执；`search-error-slot.js` 管当前短错误实例；calendar 只管日期控件。view 接输入和焦点，view-model/presentation 只生成投影和 DOM。
- **日期加载交接：** 改条件后复用同一 reader 已成功落库的正常进度，继续未完成游标；旧结果不能回写新条件。读取层只用账号绑定的完整检查点签收识别自身进度，不放宽其他读取者的检查点保护，不自动恢复手动暂停或错误停止；最后一页迟到仍可稳定完成。
- **导航边界：** 关键词交给官方搜索路由定位/高亮；日期走共享 latest 导航。官方接受路由不等于定位完成，不用整页跳转兜底。
- **退出/取消：** 条件变化替换旧查询代际，普通新交互撤销旧短错误权限；翻页或容量调整不等于重新查询。离开/隐藏暂停继续读取并撤销本栏导航；文档重握手可按既有契约保留已授权导航，迟到失败不能复活旧提示。查询结果与导航回执不是同一个 owner。
- **提示原因和下一步：** 查询模型保留失败事实及 retryable，按入口重新查询/刷新；瞬时错误显示不重启读取。
- **消失条件：** 当前瞬时错误沿用 5000 ms，或被新交互/通道撤销/退出清除；重绘、换语言、读取同一错误不重置倒计时，历史 readErrors 不会复活提示。导航 toast 另按意图归属。
- **表面：** `search.error` 与搜索导航 toast；文案在 `search.json`，部分公共原因在 `common.json` / `titles.json`。

## 6. 导出

- **负责/输入：** 当前/批量、导出篮和选择草稿、格式/内容选项、预览、资源、生成与保存；输入已确认账号、精确正文/消息及来源。
- **输出：** 统一文档、文件计划、文件、任务与下载回执。只有浏览器 downloads 完成才算保存完成。
- **状态 owner：** `export-selection.js` 唯一写导出篮/来源草稿，`export-basket.js` 是纯转换；`export-context-controller.js` 管正文读取/缓存和代际；`export-preview-controller.js` 管全屏预览会话；`export-resources.js` 管图片请求；`export-job-controller.js` 管后台任务投影/轮询/提交不确定性。view 管控件、折叠、滚动和装配，markup 只呈现。
- **跨栏边界：** 收藏/书签/日期结果只读 selection 状态并发意图；`app/sidepanel/export-workflow.js` 管前往来源、返回、取消/提交。资料变化先更新 selection，再读投影；不依赖哪个栏目先 render。
- **退出/取消：** 离开来源丢弃未提交草稿，已提交导出篮保留。离开导出页使本页读取/预览失效，不取消后台任务；明确取消才终止生成。后台一次一项、不自动排队。
- **提示原因和下一步：** 账号、当前正文、批量正文、生成错误和后台任务分开；部分资源失败不能伪装成完整成功，提交/保存未知只核对，不再下载一份。
- **回复中的读取边界：** 共享快照采用有界事件合并，持续 DOM 输出不能一直推迟正在回复通知。当前会话模式下，原生快照明确进行中时撤销旧正文与预览、停止读取及新提交；当前/批量 API 共用适配入口，只拒绝当前活动回合尾端明确的 in_progress，不把标题、消息条数、缺字段或工具 end_turn:false 当作完成判据。未观察到 busy 不是证明全文已追上网页。
- **短暂未就绪与任务归属：** 当前正文明确 pending 后最多按 400/1000/2000ms 补读三次，耗尽显示既有重读提示；普通内容/布局变化不重置预算，切账号/路由、隐藏和迟到回包均受代际约束。批量 pending 原子失败、不设自动补读，保留显式刷新或重新进入批量模式的既有读取语义；当前会话的新任务准入再检查既有新鲜快照，明确 pending 不是未知提交，不核对或自动重交。已接收任务继续使用冻结计划。
- **消失条件：** 普通读错在重试/来源失效时替换；任务失败卡不自动收起，成功/警告按既有时长收起，悬停/聚焦/展开警告/页面隐藏暂停。任务事实与卡片显示分离，收起不是取消或重做。
- **表面：** `export.account`、`export.current.error`、`export.batch.error`、`export.generation.error`、`export.job`；文案在 `export.json`。

### 导出内容保真补充

- **默认内容（2026-09-30 用户确认）：** 消息时间、消息编号开启；可见思考、工具过程、网页检索过程、最终引用来源、图片与附件默认关闭。投影默认值由 normalize 唯一维护，UI 直接复用；用户主动开启后，切格式或切栏目不擅自重置。
- **媒体开关文案（2026-10-01 用户确认）：** 统一简体短标签“图片与附件”，不加格式解释或括号；各格式行为与默认值保持，不增加主界面排除内容警告、不改变手动刷新入口。
- **媒体格式规则（2026-09-30 用户确认）：** Markdown/TXT 在媒体开启时仅保留图片、附件的名称/说明和可用链接，不显示图片、不读取图片地址或下载图片二进制。Markdown 不再生成媒体嵌图语法或图片资源包；单会话输出一个 .md 文件，多文档仍可 ZIP。已有代码示例中的图片语法保持字面原文，不能全局正则删除。
- **PDF/JSON 边界：** PDF 在媒体开启时嵌图；JSON 保留规范化媒体结构及原有地址解析能力，不嵌入图片二进制。MD/TXT 的媒体说明不存在可用公开链接时复用原会话入口，不编造附件直链、不输出标记为临时的签名地址。附件文件本体不属于现有导出备份范围。

- 原生网页引用在可确认来源时输出可读标题与链接；元数据缺失或冲突时不猜链接、不把内部编号当正文。最终来源开关控制文末来源区，不抹掉正文已有引用链接。
- 原生图片标记、结构化图片、普通 Markdown 图片进入同一媒体模型；关闭图片与附件后不保留图片占位或请求其资源。代码示例中的图片语法保持原文。
- Markdown 保留标准链接；TXT/PDF 保留标题与完整地址，PDF 添加可用链接注释；预览和实际文件的内容规则一致，PDF 分页/字体排版仍以实际文件为准。
- JSON 保留规范化后的结构数据；消息时间开关控制外层消息展示时间，不改动子片段/会话的审计元数据，也不代表附件二进制备份。
- 取消生成以先持久化意图为准：后台清理暂时失败不能让迟到结果重新启动下载。真实保存完成仍优先于取消宣告。
- 图片元数据里的完整 Markdown 图片结构在原生适配层提取图片地址、纯说明和来源；格式层不猜 caption，不把嵌套图片语法当名称输出。
- 明确生成图片工具的可见结构化图片结果属于助手正文，不依赖工具过程开关。工具说明、普通工具图片、隐藏/推理内容不被这条规则提升；图片与附件开关仍统一控制全部图片。
- 角色名称编辑只保存原始草稿，空值允许保持；默认名称只显示为 placeholder，并用于摘要、预览与导出兜底。重绘、失焦、语言变化或任务进度不得回填正在编辑的名字。
- PDF 表格一行若能放入新页（扣除重复表头），则整行换页；只有超高行才拆。异常超高表头完整绘制一次，不无限重复阻断正文。
- PDF 回退字体按常规/中等字重分别选择；保留预制中文字体片段整片嵌入，禁止把文本可提取误当字形可见性验证。字体优化必须验证实际渲染，不靠删除字库减小文件。
- 本轮证据与未验收边界见 [VALIDATION](VALIDATION.md)。

## 7. 设置

- **负责/输入：** 语言、时区、主题、资料备份/导入预览/确认恢复，以及主动复制/清空诊断；输入偏好、账号 owner、文件与确认。
- **输出：** 偏好补丁、资料备份、恢复请求；资料备份不是完整聊天导出。
- **状态 owner：** `settings-view.js` 拥有设置控件，共享 preference controller 读写；`library-backup-view.js` 拥有备份交互/结果，后台 backup service 校验预览有效期和恢复事务。
- **退出/取消：** 未提交导入预览可撤销；已提交恢复与“栏目可见”分开。切出设置不能抹掉结果未知；恢复账本按账号保留，只向匹配账号显示。它仅存在于当前侧栏文档，关闭/重载侧栏不承诺恢复这份界面账本；不能把它说成持久化备份回执。
- **提示原因和下一步：** 文件不合法重新选文件，连接失败按入口恢复；提交回执丢失/核对失败提示查看资料，不自动重写恢复。
- **消失条件：** 进行中、错误、结果未知是独立状态；未知结果无 TTL、不因换栏消失。用户先查看资料，再明确点击已核对才释放导入锁：这不代表恢复成功、不改资料或重放恢复。偏好读写状态由共享表面呈现；权威读取恢复清除旧读取失败，不能因普通重绘或默认值回填伪装恢复。
- **排查日志：** `diagnostics-view.js` 固定属于设置底部，位于业务表单外，以留白和细线与资料备份分隔；上方设置独立滚动。只在用户点击时复制或确认后清空，取消不删记录，初始不展示状态、成功反馈 3 秒后清除。断连时设置仍可进入并使用日志，其他栏目绝不显示日志；六栏及设置业务表单保留原准入锁。报告不含聊天/账号/凭据、不联网，浏览器会话结束清空，与资料备份和操作恢复锁完全独立。
- **表面：** `settings.backup.status`、`shell.preferences`；文案在 `settings.json` / `common.json`。

## 共享底座

| 目录 | 使用方 / 所有权 |
| --- | --- |
| `platform/library/` | 收藏、书签、备份、导出：身份、事务、修订和加载；不决定布局 |
| `platform/catalog/` | 日期搜索、批量标题：目录读取/缓存/checkpoint；不是正文库 |
| `platform/session/` | 页面业务共同准入/失效；不自动重放写入 |
| `platform/navigation/` | 收藏、书签、搜索：每标签意图、撤销与定位；不复制三套执行器 |
| `platform/preferences/` | 全局偏好读写及状态；标题规则独立 |
| `platform/storage/` | IndexedDB 结构；领域规则不塞回数据库层 |
| `platform/chatgpt/` | 页面/API、绑定、快照、观察、路由适配 |
| `platform/ui/`、`theme/`、`time-format.js` | 公共控件/样式、主题和时间计算；不拥有栏目业务 |
| `messages/` | 文字、通用提示生命周期、登记、观测；不是业务重试或恢复状态机 |

### 收藏/书签临时界面

- 菜单的关闭与回焦由 platform/ui 的 library-transient-ui 共用：外点、Esc、隐藏、离栏和切组撤销旧浮层；Esc 下一帧回到原按钮，IME 候选期不截键。新渲染/退出使旧焦点任务失效。菜单切换图标层时按事件捕获阶段的归属判断，不误关刚打开的层。
- group-name-editor 只保存名称草稿和字段校验。新建/改名允许暂时为空，提交才 trim；空名显示同一个 groupNameRequired，不发请求、不关闭、不回填默认名。修正时局部移除错误，保留输入法和光标。无效提交在恢复滚动后只调整分组视口，使完整编辑行及提示可见，不移动整页。
- panel-confirmation 是侧栏文档内共用的单个确认框，默认取消，Enter/Esc 不误删、不触发底层返回。具体栏目保持删除目标和业务代际；离栏、隐藏、身份(account/document/epoch)失效、目标移除或改名都会撤销待确认。await 后再次验证代际及目标，普通快照/翻译更新不撤销有效确认；删除组仍只把内容移回未分组。
- library-entry-menu 和 library-overlay-position 共用移组呈现与边界定位：未分组及有效自定义组、当前组禁选、长列表内部滚动。目标 ID 和授权仍由各栏目验证，不共享业务仓库；过期按钮不能操作新目标。

## 提示检查方法

从 [MESSAGE_INDEX](MESSAGE_INDEX.md) 找到文字 → 稳定键 → catalog → 实际调用 → 表面 owner → 原因/下一步/消失条件。改文字只改 catalog；改显示规则要改 owner 和回归，不靠改空字符串隐藏问题。

公共 lifecycle 分为 `transient`（短反馈）、`condition`（条件仍存在）、`operation`（操作/结果待解决）。只有 transient 可设超时。新实例替换旧实例后，旧计时器不能清除新提示；重绘和翻译不创建新操作授权。

诊断是独立观测，不能以稳定消息键推断唯一根因。跨上下文 session 记录只含允许常量和生成关联号，不含内容/账号/凭据，浏览器会话结束清空；具体入口和限制见 [DEVELOPMENT](DEVELOPMENT.md)。没有记录或未保留类型化原因时必须写明证据缺口。

## 每栏验收清单

- [ ] 有唯一入口、状态 owner、样式、catalog；共享能力没有复制。
- [ ] 正常/加载/空/错误/重试/退出都清楚，部分失败不冒充空结果或完整成功。
- [ ] 每条提示能解释出现原因、用户下一步、替换/消失条件。
- [ ] 新交互、切栏、隐藏、切会话/账号后旧回包不污染当前状态。
- [ ] 未知写入保留核对入口，任务事实不与卡片可见性混用。
- [ ] 跨栏选择、导航、取消遵守准确归属，不通过绘制偷偷改业务。
- [ ] 分开记录代码、合成浏览器与真实账号证据，不把其中一种当成全部验收。
