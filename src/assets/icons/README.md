# ChatGPT Tidy 图标

保留原来的六瓣轮廓、比例与透明背景，指针不再镂空。

| 用途 | SVG 源稿 | PNG 文件 |
| --- | --- | --- |
| 工具栏默认/浅色与原生侧栏顶部：黑主体、白指针、细白描边 | `tidy-outlined.svg` | `tidy-outlined-{16,32,48,128}.png` |
| 深色工具栏：白主体、黑指针、细黑描边 | `tidy-white.svg` | `tidy-white-{16,32,48,128}.png` |

修改 SVG 后运行 `npm run build:icons`，用 `npm run build:icons -- --preview` 同时生成白色、深色与薄荷色背景预览（在 `.tmp/logo-preview.png`），包含两种图标的真实 16px 大小。需要本机安装 Chrome 或 Edge；自定义位置可用 `--browser <路径>` 或 `BROWSER_BIN` 环境变量。渲染使用独立临时资料夹，不读取用户浏览器，不访问外网，也不需要额外图片依赖。

想调参数时：SVG 的画布固定为 24 单位；指针宽度 `1.65`，两种描边宽度均为 `1.3`。描边先画、原色主体后画，避免花瓣内部出现接缝；细描边也能在主题信号尚未同步或工具栏使用自定义配色时保留轮廓。

`npm run build:icons -- --check` 可检查当前浏览器能否复现已提交 PNG；不同浏览器版本可能改变抗锯齿，更新后请先看预览，再更新图标测试中的哈希。浏览器顶部配色由工具栏逻辑处理，不根据 ChatGPT 网页颜色猜测。
